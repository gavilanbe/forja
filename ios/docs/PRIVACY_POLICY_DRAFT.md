FORJA es una aplicación de registro y planificación de entrenamiento creada por Nahuel Gavilán Bernal.

## Datos que trata la aplicación

La aplicación permite introducir un nombre de perfil, preferencias de entrenamiento, rutinas, sesiones, pesos, repeticiones, RIR, notas y registros opcionales de molestia.

## Dónde se guardan

Estos datos se almacenan localmente en el dispositivo. La versión actual no utiliza cuentas, analítica, publicidad ni servidores propios, y el desarrollador no recibe ni puede consultar la información introducida.

La persona usuaria puede exportar voluntariamente una copia JSON mediante el selector de archivos de iOS. FORJA no controla el destino elegido ni los servicios de terceros en los que la persona decida guardarla.

## Notificaciones

Si la persona las autoriza, FORJA programa notificaciones locales para avisar del final de un descanso. No se utiliza un servidor de notificaciones y no se envían datos al desarrollador.

## Salud y uso previsto

FORJA organiza el entrenamiento y no ofrece diagnósticos, tratamiento médico ni sustitución de una valoración sanitaria o fisioterapéutica.

## Eliminación

Cada perfil puede eliminarse desde Perfil. La eliminación borra del dispositivo sus sesiones, series, preferencias y personalización. También se pueden eliminar todos los datos desinstalando la aplicación.
