# Páginas públicas de FORJA

Contenido estático listo para publicar bajo `https://ngavilan.dev/forja/`:

- `index.html` → `/forja/`
- `privacy/index.html` → `/forja/privacy/`
- `support/index.html` → `/forja/support/`
- `store.css` → `/forja/store.css`

No usa JavaScript, cookies, analítica, fuentes remotas ni recursos de terceros. Antes de desplegar:

1. Confirmar que `support@ngavilan.dev` recibe y reenvía correctamente.
2. Copiar la carpeta al origen que publica `ngavilan.dev`.
3. Comprobar ambas rutas sin autenticación, en móvil y escritorio.
4. Introducir las URLs finales en App Store Connect.
