# Instrucciones del proyecto FORJA

Antes de actuar, lee completamente:

1. `docs/SUPER_PROMPT_FABLE.md`
2. `docs/PRODUCT_BRIEF.md`
3. `docs/ARCHITECTURE.md`
4. `docs/ROUTINE.md`
5. `docs/DEPLOYMENT.md`

El manual DOCX de `reference/` es la fuente para técnica, colocación, errores y alternativas de ejercicios.

Principios no negociables:

- La aplicación funciona offline después de su primera instalación/carga.
- IndexedDB es la fuente primaria de datos del usuario.
- Guardar una serie nunca espera a la red.
- La UI es original, pixel art y diseñada ad hoc; no es una plantilla con iconos pixel.
- Toda la interfaz está en español.
- La racha es semanal y respeta los días de descanso.
- Carlos replica exactamente las sesiones compartidas; no se le inventan compensaciones.
- No se añaden dependencias de pago ni backend obligatorio para la v1.
- No crear remoto, commit, push, PR ni despliegue sin autorización explícita del usuario.
- Verifica visualmente la aplicación móvil y prueba el modo offline antes de declarar el trabajo terminado.
